## 自动测试标记

可测试的对话区块上方带一行状态标记：

```
;@AT <状态> <TID>       例如  ;@AT 待自动测试 K6_300_恋人
```

- `<状态>` ∈ `待自动测试 · 待手动测试 · 测试通过 · 测试失败`
- `<TID>` 是稳定的唯一联结键，脚本据此把测试输出回写到对应源码区块的状态标记上。
