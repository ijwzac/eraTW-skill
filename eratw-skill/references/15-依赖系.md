# 15. 依赖系（IRAI 委托）写作速查

角色委托玩家花时间做事（采集/送信/找人/讨伐/陪玩…），完成后给报酬+感谢。写法＝新建一个 `M_KOJO_K{id}_依頼.ERB`，实现两个标签。

## 标签
- `@M_KOJO_IRAIEXIST_K{id}(IRAI_NO)`：存否控制。`RETURN 0` 禁止该角色发出某类一般委托，默认 `RETURN 1`。（例：胆小角色禁讨伐 `CASE 12 RETURN 0`）
- `@M_KOJO_IRAI_K{id}(ROLE, SCENE, IRAI_ID)`：主口上。三层 `SELECTCASE`：**ROLE →（一般依頼？→ 依頼名）→ SCENE**。
  - 自定义参数名，body 头须 `#DIMS ROLE` / `#DIMS SCENE` / `#DIM IRAI_ID`（+ `#DIM CLIENT_ID`）声明。
  - 分发：`KOJO_MESSAGE.ERB:983` `TRYCALLFORM M_KOJO..._IRAI_K{id}(ARGS:1, ARGS:2, ARG:2)`。

## ROLE 枚举（该角色在这次委托里的立场）
| ROLE | 含义 | 出现的 SCENE |
|---|---|---|
| `"CLIENT"` | 委托人**本人**（绝大多数台词） | 全部阶段 |
| `"TARGET"` | 被卷入的**第三方对象**（"把信送给她"里的她） | 仅 `依頼実行直前`/`依頼実行直後` |
| `"NO_REPORT"` | 免报告型委托达成后再遇委托人 | 仅 `依頼報告不要` |

## SCENE 枚举（阶段）
`依頼提示時`(=**拜托**) / `依頼非受託時` / `依頼受託時` / `依頼確認時` / `依頼破棄時` / `依頼実行直前` / `依頼実行直後` / `成功報告時`(=**感谢**) / `失敗報告時` / `依頼報告不要`。
- **最少写「依頼提示時 + 成功報告時」即可**，其余 SCENE 留空则回落引擎通用旁白。
- `実行直前/直後` 建议加 `PRINTFORMW`（其余引擎自带停顿，用 `PRINTFORML`）。

## IRAI_ID 编码
`IRAI_ID = 委托人ID×1000 + 子ID`。辅助函数（都在 `COMF\依頼\FUNC_IRAI.ERB`）：
- `IRAI_ID_TO_CLIENT(IRAI_ID)` → 委托人ID；`IS_COMMON_IRAI(IRAI_ID)` → 是否一般依頼（子ID 1~99）；`STR_DATA_IRAI(IRAI_ID,"依頼名",CLIENT_ID)` → 取该委托的**依頼名字符串**（就是 `SELECTCASE` 要 `CASE` 的值）。
- 子ID 1~99 = **一般依頼**（全角色共用，用 依頼名 匹配）；>100 = **固有依頼**（角色专属数据文件 `固有依頼NNN_角色.ERB`）。

## 一般依頼 `依頼名`（`CASE` 值，必须与 `COMF\依頼\一般依頼NN_*.ERB` 字节一致；繁简混杂勿改字）
| 子ID | `依頼名`（CASE 值） | 業種 |
|---|---|---|
| 1 | `"幫忙做掃除"` | 作業 |
| 2 | `"給花澆水"` | 作業·**免报告型**（走 `NO_REPORT`） |
| 3 | `"一起玩吧"` | — |
| 4 | `"想要学習料理"` | — |
| 5 | `"関于特訓"` | — |
| 6 | `"誰来告訴我！"` | — |
| 7 | `"大掃除還沒結束"` | 作業 |
| 8 | `"送信"` | 伝令 |
| 9 | `"誰的遺失物"` | **免报告型** |
| 10/11 | `"怎麼也找不到"` | 捜索 |
| 12 | `"想要制裁TA！"` | 討伐 |
| 13 | `"想吃美味的魚"` | 調達 |
| 16 | `"倾听烦恼！"` | — |

（業種大类：1作業/3調達/4伝令(人物)/5伝令(場所)/6捜索(人物)/7捜索(場所)/8討伐/99其他。）

## 骨架（照 K49 さとり 精简；标识符原文、台词中文）
```
@M_KOJO_IRAIEXIST_K{id}(IRAI_NO)
#DIM IRAI_NO
SELECTCASE IRAI_NO
	CASE 12          ; 讨伐——胆小角色禁发
		RETURN 0
	CASEELSE
		RETURN 1
ENDSELECT

@M_KOJO_IRAI_K{id}(ROLE, SCENE, IRAI_ID)
#DIMS ROLE
#DIMS SCENE
#DIM  IRAI_ID
#DIM  CLIENT_ID
CLIENT_ID = IRAI_ID_TO_CLIENT(IRAI_ID)
SELECTCASE ROLE
CASE "CLIENT"
	RESETCOLOR
	SIF FLAG:口上色
		CALL M_KOJO_COLOR_K{id}
	IF IS_COMMON_IRAI(IRAI_ID)
		SELECTCASE STR_DATA_IRAI(IRAI_ID, "依頼名", CLIENT_ID)
			CASE "一起玩吧"
				SELECTCASE SCENE
					CASE "依頼提示時"        ; 拜托
						PRINTFORML …
					CASE "成功報告時"        ; 感谢
						PRINTFORMW …
				ENDSELECT
			; …其它 依頼名…
		ENDSELECT
		RETURN 1
	ENDIF
CASE "TARGET"
	SELECTCASE SCENE
		CASE "依頼実行直前"
		CASE "依頼実行直後"
	ENDSELECT
CASE "NO_REPORT"
	IF IS_COMMON_IRAI(IRAI_ID)
		SELECTCASE STR_DATA_IRAI(IRAI_ID, "依頼名", CLIENT_ID)
			CASE "給花澆水"
				PRINTFORMW …
		ENDSELECT
	ENDIF
ENDSELECT
RETURN 1
```
- 每个 SCENE 内可再叠好感层（`TALENT:恋人/恋慕/思慕`）。
- 一般依頼的成败/奖励由 `一般依頼NN_*.ERB` 处理，口上**只管台词**，别动 SOURCE/ITEM。
- 范例：`049 Satori\さとり(24.5.14)\M_KOJO_K49_依頼.ERB`（全文，按 ROLE→依頼名→SCENE 四层最完整）。

## debug 手动测试
委托挂载在 `CFLAG:{id}:403`(依頼状況) 与 `CFLAG:{id}:404`(依頼内容=IRAI_ID)。
- **纯测台词（最省事，绕过所有条件）**：调试台直接调用——
  `CALL M_KOJO_IRAI_K{id}("CLIENT","依頼提示時",{id}001)`（测拜托）
  `CALL M_KOJO_IRAI_K{id}("CLIENT","成功報告時",{id}001)`（测感谢）
  （`{id}001` = 角色ID×1000 + 子ID1；换子ID测别的类型。）
- **走完整链路**：`CFLAG:{id}:404 = {id}003`（依頼内容=一起玩吧）、`CFLAG:{id}:403 = 1`（未受託），再对该角色用 **[366] 依頼を聞く** → 触发拜托台词；完成后 `CFLAG:{id}:403 = 3`（達成）再 [366] → 感谢台词。
- 状态码 `CFLAG:{id}:403`：-1発生直後 / 1未受託 / 2依頼中 / 3達成 / 4期限切れ / 5報告忘れ / 6失敗。

**关键文件**：分发 `KOJO_MESSAGE.ERB:972-987`；范例 `M_KOJO_K49_依頼.ERB`；系统核心 `COMF\依頼\FUNC_IRAI.ERB` `CTRL_IRAI.ERB` `COMF366 依頼を聞く.ERB`；一般委托数据 `COMF\依頼\一般依頼01~18_*.ERB`。
