# 12. 命令速查表（口上作者向）

## 如何使用本表

写某个日常/互动指令的对话时，你在角色的 `_COM_K{id}_{命令号}` 标签体里能读到哪些游戏状态，是由**该指令主体（引擎 COMF）在调用你的口上前，往 TFLAG / TCVAR / CFLAG / COM_STR 等槽位里塞了什么**决定的。本表把每个常写指令的「可读 state 清单」「取值含义」「触发/分发要点」整理成速查条目，供你在写分支（`SELECTCASE TFLAG:193` 之类）时直接查。

用法要点：
- **成败几乎都在 `TFLAG:193`**（并非全部同一套取值——见各条），`TFLAG:192` 是你在 `@M_KOJO_SUCCESS_COM_*` 里**写入**的成败强制值（-2=指令终止 / -1=强制失败 / 0=依 COM 判定 / 1=强制成功或大成功），不是给你读的。
- **只有被选中的 TARGET 的口上会被调用**。COMMAND 类分发不会把 `_COM_` 标签派发给「在场旁听的其他角色」——旁听者的反应写在引擎默认叙述里（`EVENT_MESSAGE_COM*.ERB`），不是口上。所以本表的「分发要点」默认都是「只对 TARGET 触发」，仅在有例外时才特别注明。
- **本 fork 把部分槽名汉化了**，写口上时必须用 fork CSV 里的实际槽名，别照抄日文模板：
  - `添い寝中` → **`陪睡中`**（如 `CFLAG:TARGET:陪睡中`，见 417/354/363）
  - `泥酔` → **`烂醉`**（`TCVAR:烂醉`，见 300）
  - `うふふ`（醉后暧昧「诶嘿嘿」模式）→ 本 fork CSV 作 **`诶嘿嘿`**（`CFLAG:诶嘿嘿 == 2`，见 310–313 的 `TCVAR:20` 子动作分支）
  - 遇到拿不准的槽名，以 `CSV\CFLAG.csv / TFLAG.csv / TCVAR.csv` 的实际写法为准。

## 本表如何生成

1. **枚举** `CSV\Train.csv` 得到「命令号 → 中文名」全表。
2. **收割 banner**：官方空模板 `reference-kojo\口上テンプレ\M_KOJO_KX_日常系コマンド.ERB` 与 `…_セクハラコマンド.ERB` 每个命令顶部的 doc-banner 是最完整、最权威的「可读 state 契约」；再抽真实口上（以 011 魔理沙 `M_KOJO_K11_日常系コマンド.ERB` 为样本）核对汉化后的实际写法。多份口上互相抄同一份 banner，会收敛到同一份清单。
3. **引擎校对**：命令专属变量（如 416 的 `使用楽器`、332 的酒判定、417 的 `陪睡中`）以引擎主体为准——日常命令主体在 `ERB\コマンド関連\COMF\日常系\COMF{命令号} *.ERB`，默认叙述在 `ERB\口上・メッセージ関連\EVENT_MESSAGE_COM300/400.ERB`。banner 可能过时/抄错时以引擎为准。

**证据文件缩写**（下文 `缩写:行号` 均可定位到绝对路径）：
- **TPL日常** = `…\reference-kojo\口上テンプレ\M_KOJO_KX_日常系コマンド.ERB`
- **TPLセ** = `…\reference-kojo\口上テンプレ\M_KOJO_KX_セクハラコマンド.ERB`
- **EVT400** = `ERB\口上・メッセージ関連\EVENT_MESSAGE_COM400.ERB`（本 SKILL 已收录副本于 `references/data/engine/`）
- **K11日常** = `ERB\口上・メッセージ関連\個人口上\011 Marisa [魔理沙]\…\M_KOJO_K11_日常系コマンド.ERB`
- **COMF{n}** = `ERB\コマンド関連\COMF\日常系\COMF{n} <名>.ERB`（引擎主体）

> 通用标签模板（下文各条只标差异）：
> `@M_KOJO_SUCCESS_COM_K{id}_{cmd}`（写 `TFLAG:192`）→ `@M_KOJO_MESSAGE_COM_K{id}_{cmd}`（调 `CALL M_KOJO_MESSAGE_COM_K{id}_{cmd}_1`）→ `@M_KOJO_MESSAGE_COM_K{id}_{cmd}_1`（口上主体，`LOCAL=1` 后写分支）。可选 `@M_KOJO_MESSAGE_MESSAGECHECK_COM_K{id}_{cmd}`（RETURN 0/1/2/3 控制是否显示地文/口上）。

### 300 会話（会話）
- 触发：对 TARGET 用「会話」。最基础的对话指令，几乎每个角色都写。
- 可用 state：
  - `TFLAG:193`：1=大成功 / 0=成功 / -1=失败 / -2=大失败（TARGET 教养比 MASTER 高 4 以上）
  - `TCVAR:302`：0=可对话 / ≥1=非恋慕时无法对话
  - `MARK:反発刻印`：≥3=无法对话（≥4 是 bug）

- 证据：TPL日常:5–9；K11日常:5–9
