# 16. 刻印(MARK)系统速查

## 是什么
`MARK:角色号:刻印名` —— **每角色持久存档变量**（与 `CFLAG`/`TALENT`/`ABL`/`EXP` 同级，随存档保存），记录「被调教/开发/情绪」铭刻的**落地等级**。值域基本 **0–3**。可省角色号（默认当前 TARGET）：`MARK:不埒刻印`，也可显式 `MARK:6:不埒刻印`。
- 与 `CUP:*` 的关系：`CUP:角色:*`（本次调教内累积的快感/情绪增量）是**判定原料（临时输入）**，引擎结算后落成 `MARK:*`（**持久输出**）。二者是两层。
- 与其它命名空间：`CFLAG`=自由语义的每角色整数标志；`TALENT`=素质/性癖（天生/永久）；**`MARK`=专用于六个「开发/情绪铭刻」计量、槽位固定、值窄（0-3）、语义就是"被调教到什么程度"**。

## 全表（`CSV\Mark.csv`）
| 编号 | 名称 | 含义 |
|---|---|---|
| 0 | `苦痛刻印` | 痛苦累积铭刻（0-3） |
| 1 | `快楽刻印` | 快感/高潮铭刻（0-3）；是不埒刻印「快乐路线」的前置门槛 |
| 2 | `不埒刻印` | ★**被开发/堕落的综合总量**（0-3），R18 台词分层的主开关 |
| 3 | `反発刻印` | 反感/敌意（0-3），越高越抗命，`>=3` 拒绝对话 |
| 4 | `反発取得履歴` | 曾达到的反发最高档（单调不降，记仇/NTR 史，使反发更难再涨） |
| 5 | `時姦刻印` | 时停(时姦)侵犯铭刻（0-3） |
| 8 | `成長` | 成长槽（非情色，预留） |

（编号 5 之后跳到 8；`不埒刻印` 等是引擎读写用的具名下标。）

## 怎么获得（引擎自动，阈值触发）
核心 `@MARK_GOT_CHECK(ARG)` @ `ERB\ステータス計算関連\TRACHECK_刻印取得.ERB`，每次调教/H 结算由 `SOURCE.ERB:879` 调用（`CFLAG:恶作剧` 模式跳过）。**只增不减。**

- **不埒刻印**（三条来源，谁先到阈值都算，取最高级，只升级）：
  - 快乐路线 `A=快Ｃ+快Ｖ+快Ｂ+快Ａ`：`>=3000/5000/9000 → LV1/2/3`（需 `快楽刻印 > 不埒刻印`）
  - 痛苦路线 `A=苦痛+恐怖`：`>=1500/2400/6000 → 1/2/3`
  - 屈服路线 `A=恭順+屈服`：`>=4500/7000/10000 → 1/2/3`
  - ⚠**快乐/痛苦两路线在时停(`FLAG:70`)或恶作剧时不生效**（被 `[SKIPSTART]…[SKIPEND]` 包住）；**屈服路线时停下仍生效**。
  - 升 LV2/LV3 顺带抬 `ABL:従順`（除非 `TALENT:感情缺乏`）。
- **反発刻印**：`取得値=反感+不快 → 500-1000/1001-2000/>2000 = 1/2/3`。排除 `MASTER`/`TALENT:反発抑制`/恶作剧/`TFLAG:150`。取得时同置 `CFLAG:心情不快`·`ブチギレ`、`TALENT:心情=-1`、下调 `従順`/`親密`。另有直接赋值处：睡眠中被侵犯、催眠抵抗、被推倒(OGAMITAOSHI +1)、翻脸事件 `@GET_ANGRY`(`COMMON.ERB:1052`) 等。
- **苦痛刻印**：`CUP:苦痛` `2000/4000/8000 → 1/2/3`。
- **快楽刻印**：`TCVAR:快楽強度`（TRACHECK_ORGASM 依高潮强度设）→ 1/2/3。
- **時姦刻印**：`TCVAR:時姦刻印取得用`（时停高潮）→ 1/2/3。

## 怎么消除/减少
- **无自然衰减**（尤其不埒刻印，只增不减，时间流逝不掉）。
- **調教リセット**（单角色重置）：`SHOP関連\ALTER_RESET_SINGLE.ERB:73-78` 把六刻印全清零。
- **版本更新**：`SHOP関連\UPDATE.ERB:963-968` 清零。
- **减反发**：`コマンド関連\願掛けパッチ.ERB:177` `MARK:反発刻印 --`（可选清 `反発取得履歴`）——这是**唯一常规"减刻印"渠道，且只针对反发**。不埒刻印没有"减一"渠道。
- **debug 直清**：`MARK:6:不埒刻印 = 0`（实例见随 skill 附带的 `reference-kojo/luna-K6/M_KOJO_K6_AUTOTEST.ERB` 的状态清理段）。

## 机械影响
- **服从/命令受理评分**：`COMORDER.ERB:165-179` `A += MARK:不埒刻印*3*T` / `A -= MARK:反発刻印*2*T`（T 随 `自尊心`：>0→4, <0→1, 否则2）。**不埒越高越听话、反发越高越抗命。**
- **反発刻印 >=3 → 无法对话**（与 `TCVAR:302` 并列的对话门）。
- **反発刻印门控好感上升**：`TRACHECK_好感度上昇処理.ERB:298-300`。
- **口上台词分层（最高频用途）**：各角色用 `MARK:不埒刻印 == n` 解锁越来越露骨的反应（全语料 9254 处）。

## 口上里怎么读（持久等级 vs 刚取得瞬间）
**持久分层（常用）**——读 `MARK:*` 当前等级：
```
IF MARK:不埒刻印 == 3
	; 完全沦陷台词
ELSEIF MARK:不埒刻印 >= 1
	; 已被开发台词
ELSE
	; 纯洁/抵抗台词
ENDIF
```
**刚取得那一帧的旁白**——写在 `@M_KOJO_MESSAGE_MARKCNG_K{id}`，读 `TFLAG`（这些是"本次刚变"的瞬时量，持久等级仍读 `MARK:`）：
- `TFLAG:24` = `11/12/13`(不埒·快乐) `21/22/23`(不埒·痛苦) `31/32/33`(不埒·屈服)——十位码记「因何而堕落」。
- 还有 `TFLAG:反発刻印取得`(槽21) / `苦痛刻印取得`(22) / `TFLAG:23`(快楽) / `時姦刻印取得`。
- **body 开头必须加守卫，否则每次动作后刷屏**：
```
SIF !TFLAG:21 && !TFLAG:22 && !TFLAG:23 && !TFLAG:24 && !TFLAG:時姦刻印取得
	RETURN 0
```
引擎默认旁白在 `EVENT_MESSAGE_MARK.ERB @MARK_MESSAGE`（角色没写 MARKCNG 时用）。模板：`reference-kojo\口上テンプレ\M_KOJO_KX_刻印取得.ERB`。

## 「不埒刻印」讲透
- **代表什么**：角色「被玷污/被开发/堕落」的**综合程度总表**，不分是被爽的、被折磨的还是被压服的——三条来源谁先到阈值都算，`TFLAG:24` 的十位码记录路线。是全游戏 R18 台词分层最通用的开关。
- **怎么涨**：持续施加快感/痛苦恐惧/让其屈服，`CUP` 累积过阈值，调教结算时自动升级、只升不降；时停/恶作剧下只有「屈服路线」能涨。
- **怎么消**：不自然掉；只能 調教リセット/版本更新清零，或 debug `MARK:X:不埒刻印 = 0`。没有针对它的「减一」。
- **口上里怎么用**：把 `MARK:6:不埒刻印` 当「她对露骨行为的接受度/堕落度」主门——`==0` 害羞抗拒 / `>=1`或`==2` 半推半就 / `==3` 彻底顺从淫乱（现成实例：随 skill 附带的 `reference-kojo/luna-K6/M_KOJO_K6_日常系コマンド.ERB` 里 301 泡茶那条的 `ELSEIF MARK:6:不埒刻印 == 3`）；刚升级那帧在 `@M_KOJO_MESSAGE_MARKCNG_K{id}` 按 `TFLAG:24` 路线码写「初次被开发」旁白（记得加 `SIF` 守卫防刷屏）。
