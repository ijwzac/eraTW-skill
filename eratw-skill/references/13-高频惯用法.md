# 13・高频惯用法目录

> 本目录是**数据驱动**统计出的作者通行写法：对 `個人口上\` 下 1758 个 ERB 文件全量 grep 得到出现频次与覆盖文件数，按频次从高到低排列，可直接照抄。频次格式为「hits=命中行数 / files=覆盖文件数」（同一角色的多版本会重复计数，仅用于体现"多不多人这么写"）。所有出处均为真实 file:line。

路径根：`ERB\口上・メッセージ関連\個人口上\`（下文出处省略此前缀）。

## 0. 头号惯用法：称呼替换（几乎每个口上每句都用）

| 模式 | 用途 | 频次 |
|---|---|---|
| `%CALLNAME:MASTER%` | 在台词里插入"玩家（主人公）对本角色的称呼"，是全语料出现最多的写法 | hits=128868 / files=1227 |
| `%CALLNAME:TARGET%` | 插入"当前对话对象"的称呼，多用于角色互相调侃/群交场景 | hits=9237 / files=183 |

- 出处：`006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_日常系コマンド.ERB` 附近的蹭手心台词。
- 坑：`CALLNAME` 取的是"称呼"而非本名；要本名用 `%NAME:X%`。

## 1. 在场 / 同房间判定

同房间判断一律以 `CFLAG:MASTER:現在位置`（玩家所在地）为锚点比对。

1. **同房间锚点比较**　`CFLAG:X:現在位置 == CFLAG:MASTER:現在位置`
   - 用途：判断编号 X 的角色是否和玩家在同一地点（在场）。`CFLAG:MASTER:現在位置` 作为"玩家当前位置"是全语料最通用的地点锚点。
   - 频次：`CFLAG:MASTER:現在位置` hits=1744 / files=262
   - 出处：`006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_日常系コマンド.ERB:533`
     `ELSEIF SHIRAHU(124) && CFLAG:124:現在位置 == CFLAG:MASTER:現在位置`

2. **在场谓词 `SHIRAHU(X)`**（配合同房间比较连用）
   - 用途：判断角色 X 是否"已加入 / 在场"，几乎总是写成 `SHIRAHU(X) && CFLAG:X:現在位置 == CFLAG:MASTER:現在位置`，表示"X 存在且和玩家同房间"。
   - 频次：`SHIRAHU(` hits=247 / files=77
   - 出处：`006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_日常系コマンド.ERB:521`
     `ELSEIF (SHIRAHU(20) && CFLAG:20:現在位置 == CFLAG:MASTER:現在位置) || (SHIRAHU(21) && …) || (SHIRAHU(22) && …)`

3. **在场人数 `GET_TARGETNUM()`**
   - 用途：取当前场景在场对象数量，用来区分"独处 / 有旁人 / 群交"，常与 `WITH_MOB()`、`DATE_HITOGOMI(...)` 一起做"是否有人看到"的判定。
   - 频次：`GET_TARGETNUM()` hits=494 / files=97
   - 出处：`002 Ruukoto [る～こと]\る～こと\M_KOJO_K2_セクハラコマンド.ERB:293`
     `IF ( GET_TARGETNUM() >= 2 || DATE_HITOGOMI(CFLAG:MASTER:現在位置) || WITH_MOB() ) && RAND:2`

4. **分组匹配 `GROUPMATCH(值, a, b, c, …)`**
   - 用途：判断第一个值是否等于后面任意一个（等价于一串 `==` 用 `||` 连接）。**注意：作者几乎从不用 `GROUPMATCH(TARGET,…)`**（该形式 hits=0）；真实高频用法是给"时段 / 指令号 / 地点 / 天气"做集合判定。
   - 频次：`GROUPMATCH(` hits=825 / files=128
   - 常见实例（按出现次数）：
     - `GROUPMATCH(TIME:2,1,6,7)` — 判断"是否深夜/清晨等时段桶"，出处 `049 Satori [さとり]\さとり\M_KOJO_K49_イベント.ERB:1213`
     - `GROUPMATCH(SELECTCOM, 19, 20, 81, 88, 89)` — 判断"当前选中的指令号属于某一类"，出处 `010 Suika [萃香]\…\M_KOJO_K10_オートあえぎ.ERB:18`
     - `GROUPMATCH(CFLAG:現在位置, 情人用宿屋, 情人旅館)` — 判断所在地属于某组地点，出处 `016 Remilia\…\M_KOJO_K16_10_日常系コマンド.ERB:11462`
   - 坑：`FINDCHARA(…)` 在个人口上里基本没人用（hits=3 / files=1），找人/判在场请用 `SHIRAHU` + 位置比较。

## 2. 关系分层（TALENT 恋爱阶位）

**恋爱关系的实际进展（升序）是：无特殊关系(中立) → `思慕` → `恋慕` →（告白成功后）`恋人`。** 即 `思慕` 是最初的好感，`恋慕` 更深，`恋人` 需玩家告白成功才达成。**`愛欲` / `セフレ`(炮友) 不在这条恋爱阶梯上，而是另一条旁支**（纯肉体关系，一般玩家较少触发；写分支时应与恋爱向并列或单独门控，别塞进 中立/思慕/恋慕/恋人 的降级链里）。

写分支时的 `IF/ELSEIF` 一般**按亲密度从高到低排列**（这样最亲密的分支先命中）：先拦 `心情不快`，再 `恋人 → 恋慕 → 思慕(或好感度高) → 熟络(好感度中) → ELSE 中立`——这是**显示顺序**（与上面的"进展升序"相反），别混淆。各阶位频次（体现哪档最常被判定）：

| TALENT 阶位 | 频次 | 在进展中的位置 |
|---|---|---|
| `TALENT:恋慕` | hits=25571 / files=1191 | 恋爱阶梯第 2 级（较深的好感/暧昧），最常被判定 |
| `TALENT:恋人` | hits=11580 / files=534 | 恋爱阶梯顶端（告白成功后） |
| `TALENT:思慕` | hits=7666 / files=527 | 恋爱阶梯第 1 级（最初的好感） |
| `TALENT:愛欲` | hits=2245 / files=179 | **旁支**：情欲档，多用于 R18，玩家较少触发 |
| `セフレ`（炮友） | hits=240 / files=64 | **旁支**：纯肉体关系，玩家较少触发 |

- 标准分层范例（一整段可照抄的骨架），出处 `006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_日常系コマンド.ERB`：
  ```
  IF FLAG:時間停止
  ELSEIF CFLAG:6:心情不快
  ELSEIF TALENT:6:恋人
  ELSEIF TALENT:6:恋慕
  ELSEIF TALENT:6:思慕 || CFLAG:6:好感度 >= 2000
  ELSEIF CFLAG:6:好感度 >= 1000
  ELSEIF CFLAG:6:好感度 >= 500
  ELSE
  ENDIF
  ```
- 另一常见排序（愛欲优先）出处：`001 Reimu [霊夢]\灵梦-少女之梦-5.28\M_KOJO_K1_2_イベント.ERB:687` `ELSEIF TALENT:愛欲`
- 坑：`TALENT:X:恋人`（带角色号）判"X 对玩家的关系"，`TALENT:恋人`（不带号）默认作用于当前 TARGET/本角色；分层块内要前后统一，别混用。

## 3. 好感度 / 心情门控

1. **好感度阈值**　`CFLAG:X:好感度 >= n`
   - 用途：以数值卡关系深浅，常见档位 `>= 500`（渐熟）、`>= 1000`（心动），与 TALENT 档并列在同一 `ELSEIF` 链。
   - 频次：`好感度 >=` hits=271 / files=61；`CFLAG:好感度` hits=306 / files=89
   - 出处：`006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_日常系コマンド.ERB:280` `ELSEIF CFLAG:6:好感度 >= 500`

2. **坏心情门控**　`CFLAG:X:心情不快`
   - 用途：角色闹别扭时优先走冷淡/拒绝台词，通常放在关系分层最前面拦截。
   - 频次：`心情不快` hits=390 / files=65
   - 出处：`006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_日常系コマンド.ERB:307` `ELSEIF CFLAG:6:心情不快`

3. **刻印门控**　`MARK:不埒刻印 == n`
   - 用途：以"不埒刻印"等级解锁越来越露骨的反应（0/1/2/3 递进），是 R18 分层的通用开关。
   - 频次：`不埒刻印` hits=9254 / files=770
   - 出处：`015 Sakuya [咲夜]\試製咲夜さん Mk-3\M_KOJO_K15_性交系コマンド.ERB:563` `ELSEIF MARK:不埒刻印 == 3`

## 4. 随机抽签

1. **`RAND:n`**（0..n-1 等概率）
   - 用途：给同一分支准备多条等价台词随机取一；也用 `!RAND:n`、`&& RAND:3 == 0` 做概率触发。
   - 频次：`RAND:` hits=47539 / files=1042（几乎人人用）
   - 出处：`006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_日常系コマンド.ERB:541` `IF (…) && RAND:3 == 0`

2. **`SELECTCASE RAND:n` + `CASE 0/1/2…`**
   - 用途：多条随机台词的标准写法，比多层 `IF RAND` 清晰。
   - 频次：`SELECTCASE RAND:` hits=21982 / files=774
   - 出处：`015 Sakuya [咲夜]\試製咲夜さん Mk-3\M_KOJO_K15_イベント.ERB:268` `SELECTCASE RAND:3`

3. **`%TEXTR("a/b/c")%`**（斜杠分隔多选一）
   - 用途：在一行里随机取一段文本，最省事的"一句话多写法"。
   - 频次：`TEXTR(` hits=2247 / files=156
   - 出处：`006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_日常系コマンド.ERB:155`
     `PRINTFORMW %TEXTR("「无聊的话……听我说两句？」/「桑尼又搞砸了恶作剧。」/「大晴天，太吵、也太亮了。」")%`
   - 坑：分隔符是半角 `/`；候选里若含 `/` 会被误切。也有作者改用 `#DIM 池 + RAND` 取，但 `TEXTR` 是主流。

## 5. 时段 / 日期

1. **时段桶 `TIME:2`**
   - 用途：把一天切成若干"时段桶"（早/午/晚/深夜…），用 `== n` 或 `GROUPMATCH(TIME:2, …)` 分支。
   - 频次：`TIME:2` hits=782 / files=97
   - 出处：`028 Mystia [ミスティア]\ミスティア\M_KOJO_K28_コマンド.ERB:6724`
     `IF TIME:2 == 1 || TIME:2 == 2` / `ELSEIF TIME:2 == 3 || TIME:2 == 4`

2. **月份 `DAY:2` / 日 `DAY:3`**
   - 用途：`DAY:2`=月（季），`DAY:3`=当月第几日；组合判生日/节日。
   - 频次：`DAY:2` hits=1583 / files=216；`DAY:3` hits=982 / files=99
   - 出处：`011 Marisa [魔理沙]\…\M_KOJO_K11_イベント.ERB:321`
     `IF DAY:2 == 3 && DAY:3 == 30 && !TCVAR:11:今天有否见面`（3 月 30 日、每天一次）

3. **时停守卫 `FLAG:時間停止`**
   - 用途：世界处于"时间停止"状态时，角色应无反应；分层块几乎总把 `IF FLAG:時間停止`（空分支）放在最前面吃掉这一情况。
   - 频次：`FLAG:時間停止` hits=1789 / files=263
   - 出处：`001 Reimu [霊夢]\霊夢\M_KOJO_K1_イベント.ERB:1878` `IF FLAG:時間停止`

4. **睡眠状态 `CFLAG:睡眠`**
   - 用途：角色睡着时走"熟睡/迷糊"专属台词。
   - 频次：`睡眠` hits=3827 / files=551
   - 出处：`001 Reimu [霊夢]\灵梦-少女之梦-5.28\M_KOJO_K1_2_日常系コマンド.ERB:2625` `ELSEIF CFLAG:睡眠`

5. **约会中 `CFLAG:X:约会中`**
   - 用途：判断/记录"是否正与某人约会中"，配合 `CHK_DATENOW(...)`、`ROAD_TO(...)` 使用。
   - 频次：`约会中`（**简体 约**）hits=861 / files=340
   - 出处：`001 Reimu [霊夢]\霊夢\M_KOJO_K1_コマンド.ERB:25` `ELSEIF CFLAG:TARGET:约会中`
   - **重要坑**：变量名是**简体 `约会中`**。写成繁/日体 `約会中` 全语料命中 **0**，引擎不会解析——务必用 `约`。

## 6. 成败 / 状态读取

1. **命令成败与反应 `TFLAG:193`**
   - 用途：命令处理后由引擎/口上写入的"结果码"，各命令自定义含义，随后据它选反应台词。常见约定：`1`=大成功、`0`=成功、`-1`=失败/抵抗、`99`=拒绝、更细的负值表示不同拒绝程度。**每个命令的具体取值见 `references/12-命令速查.md`。**
   - 频次：`TFLAG:193` hits=9668 / files=524
   - 语义注释出处：`007 Star [スター]\スターサファイア\M_KOJO_K7_セクハラコマンド.erb:73` `;TFLAG:193(1=大成功 0=成功 -1=失敗)`
   - 读取用法出处：`001 Reimu [霊夢]\霊夢\M_KOJO_K1_コマンド.ERB:726` `IF TFLAG:193 == -1` … `:734 IF TFLAG:193 == 1`

2. **醉度门控 `BASE:酒気`（命令专属状态）**
   - 用途：判角色醉到什么程度，阈值常写成 `MAXBASE:酒気` 的比例（如 `> MAXBASE:酒気/10*8` 约八成、`> …/2` 半醉）。萃香/勇儀等酒鬼角色高频使用。
   - 频次：`BASE:酒気` hits=997 / files=58；`MAXBASE:酒気` hits=446 / files=51
   - 出处：`010 Suika [萃香]\萃香 自制别人\M_KOJO_K10_日常系コマンド.ERB:380`
     `ELSEIF TALENT:恋慕 && BASE:酒気 > (MAXBASE:酒気 / 10) * 8`

## 7. 同格守卫（提前 RETURN）

- **模式**　`SIF CFLAG:X:現在位置 != CFLAG:MASTER:現在位置` → 紧跟 `RETURN 0`（或 `RETURN`）
- 用途：进入某段口上前先做"不同房间就直接退出"的守卫，避免不在场时误触发台词。是配对第 1 类同房间判定的"反向早退"写法。
- 出处：`006 Luna [ルナ]\露娜切露德_重制\M_KOJO_K6_イベント.ERB:159` `SIF CFLAG:6:現在位置 != CFLAG:MASTER:現在位置`
- 进阶（群交/多目标同格）：`014 Cirno [チルノ]\⑨之先行者十一号\M_KOJO_K14_2_函数.erb:774`
  `SIF (CFLAG:(TARGET:COUNT):現在位置 != CFLAG:MASTER:現在位置) || (CFLAG:(TARGET:COUNT):現在位置 != CFLAG:14:現在位置)`
- 坑：`SIF` 只管下一行；要退出多行/整段请改用 `IF … RETURN 0 … ENDIF`。

## 附：三条纠偏提示

1. **别写 `GROUPMATCH(TARGET, …)`**——语料里零命中；判在场用 `SHIRAHU + 現在位置` 比较，`GROUPMATCH` 留给时段/指令号/地点集合。
2. **"约会中"只认简体 `约`**——`約会中`（繁/日）= 0 命中，会静默失效。
3. **分层块顺序有套路**：`FLAG:時間停止 → CFLAG:睡眠/心情不快 → TALENT 由亲到疏 → 好感度阈值 → ELSE`，照抄第 2 节 Luna 的骨架最稳。
